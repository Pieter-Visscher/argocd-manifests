requirements:
	auth-dns:
		Database backend:
			postgres:
				cloudnative-pg
				https://doc.powerdns.com/authoritative/backends/generic-postgresql.html
				introduces a SPOF, if DB backend is down all AZ are down 

			LMDB:
				sidecar container on auth-dns
				https://doc.powerdns.com/authoritative/backends/lmdb.html
				each AZ has its own, independent database backend, changes are synced through an S3 bucket
				use public S3 bucket such as AWS or self hosted like garageFS. If S3 is down changes cant be pushed, but DNS is still available.
				
				when using garage FS each site should have its own S3 endpoint.
